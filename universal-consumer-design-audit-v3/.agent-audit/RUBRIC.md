# AI / TEMPLATE RISK — separate 0–100

0 = highly product-specific  
25 = minor generic patterns  
50 = noticeable template grammar  
75 = strong template/generic feel  
100 = nearly interchangeable generic design  

Potential signals:
- meaningless glow/gradient
- excessive glass cards
- excessive pills/chips
- generic dashboard composition
- random decorations
- stock motivational copy
- no product-specific visual idea
- same radius/shadow everywhere without hierarchy

Do not infer actual AI usage.
