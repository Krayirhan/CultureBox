# Research Protocol

## Evidence hierarchy

### E4 — REAL PRODUCT
- real device
- emulator/simulator
- real taps/input/swipes
- runtime screenshot
- UI hierarchy

Preferred:
Maestro MCP / Maestro CLI.

### E3 — DESIGN SOURCE
- Figma
- design tokens
- components
- approved design source

### E3 — PRODUCT CONTEXT
- PRODUCT_PROFILE
- visible copy
- store positioning
- product docs

### E2 — CODE
Useful for:
- labels
- conditional states
- navigation definitions
- persistence intent

Not sufficient for rendered behavior.

### E2 — COMPETITOR
Use only for a specific question.

### E1 — USER VOICE
- Play Store
- App Store
- Reddit
- support feedback

### E0 — EXPERT INFERENCE
May guide a hypothesis; not measured fact.

## Device strategy

Use target devices.

If unknown:
- one mainstream modern phone primary
- compact/tablet/landscape only if relevant

## Research stopping rule

Stop when more research is unlikely to change:
- score
- severity
- fix direction
- confidence
